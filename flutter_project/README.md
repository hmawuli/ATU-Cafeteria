# ATU Cafeteria Mobile App (Flutter Cross-Platform)

A full cross-platform food pre-ordering and live 4-stage order tracking application for Accra Technical University (ATU) Cafeteria. Supports **iOS (iPhone)**, **Android**, and **Web**.

---

## 📱 Features
1. **Multi-Role Login**: Students, Vendors (Kitchens), and Cafeteria Admins.
2. **Dynamic Food Menu & Cart**: Real-time pricing, descriptions, and cart checkout.
3. **Live 4-Stage Order Progression**:
   - `Received` -> `Preparing` -> `Out for Delivery` -> `Delivered`
4. **Real-Time Streaming**: Push notification updates and status sync.
5. **Pickup PIN Verification**: Secure counter handoff code.

---

## 🚀 How to Run on Mac / iPhone (iOS)
```bash
# 1. Install Flutter dependencies
flutter pub get

# 2. Launch iOS Simulator or connect your physical iPhone
open -a Simulator

# 3. Run the application
flutter run -d ios
```

---

## 🤖 How to Run on Android
```bash
flutter run -d android
```

---

## 🌐 How to Run in Chrome / Web
```bash
flutter run -d chrome
```
